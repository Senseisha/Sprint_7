# Sprint_7
Файл test_create_courier включает в себя следующие тесты:
1. успешное создание курьера;
2. успешный запрос возвращает {"ok":true};
3. запрос возвращает правильный код ответа;
4. чтобы создать курьера, нужно передать в ручку все обязательные поля;
5. нельзя создать двух одинаковых курьеров;
6. если одного из полей нет, запрос возвращает ошибку;
7. если создать пользователя с логином, который уже есть, возвращается ошибка.

Файл test_login_courier включает в себя следующие тесты:
1. курьер может авторизоваться;
2. для авторизации нужно передать все обязательные поля;
3. успешный запрос возвращает id;
4. система вернёт ошибку, если неправильно указать логин или пароль;
5. если какого-то поля нет, запрос возвращает ошибку;
6. если авторизоваться под несуществующим пользователем, запрос возвращает ошибку.

Файл test_create_order_ana_get_list_of_orders включает в себя следующие тесты:
1. можно указать один из цветов — BLACK или GREY;
2. можно указать оба цвета;
3. можно совсем не указывать цвет;
4. тело ответа содержит track;
5. в тело ответа возвращается список заказов.

Файл test_delete_courier включает в себя следующие тесты:
1. успешный запрос возвращает{"ok":true};
2. неуспешный запрос возвращает соответствующую ошибку;
3. если отправить запрос без id, вернётся ошибка;
4. если отправить запрос с несуществующим id, вернётся ошибка.

Файл test_accept_order включает в себя следующие тесты:
1. успешный запрос возвращает{"ok":true};
2. если не передать id курьера, запрос вернёт ошибку;
3. если передать неверный id курьера, запрос вернёт ошибку;
4. если не передать id заказа, запрос вернёт ошибку;
5. если передать неверный id заказа, запрос вернёт ошибку.

Файл test_get_order включает в себя следующие тесты:
1. успешный запрос возвращает объект с заказом;
2. запрос без номера заказа возвращает ошибку;
3. запрос с несуществующим заказом возвращает ошибку.
